----> #!/bin/bash -> se include in antetul fisierului

----> echo <=> print -> argumentul -e permite interpretarea secventelor speciale e.g. '\n' new line
			argumentul -n previne scrierea pe o noua linie
			sintaxa : echo "text" > fisier.txt suprascrie fisier.txt cu textul "text"
			sintaxa : echo "text" >> fisier.txt scrie la finalul fisierului textul "txt"

----> tee fisier.txt ia outputul din spatele lui prin | si il scrie in fisierul dat. daca nu se doreste suprascrierea folosim -a
----> argumentele $1,$2,$3... li se atribuie pe rand din console ( 2 argumente : $1 si $2 o sa le contina )
----> argumentul $0 contine nume comenzi ( e.g. am apelat programul ./a in $0 se va afla ./a )
----> $* sau $@  - toate argumentele primate din linia de comanda
----> $# - numarul de argumente din linia de comandă
----> $? - codul de ieșire al comenzii anterioare ( e.g. '0' - s-a executat cu success )
----> e mai sigur sa ne referim la argumente cu "" ( e.g. "$1" )
----> shift 3 - shiftează spre stânga argumentele. ( $0 ramane neschimbat)
----> << test -f a.txt >> este acelasi lucru cu << [ -f a.txt ] >> ( se retuneaza true sau false )

ls -> list the content of the current directory
cat ARGUMENT -> see the content of a file, specified by the ARGUMENT
ls -l -> see the contend of the current directory, but with its specifications
ls -l -a -> as previously, but more detailed
mkdir NAME -> create a directory with name NAME
ls -l --color=never -> display the current directory, but without colors
pwd -> shows the path
man ARGUMENT -> look for the ARGUMENT in build-in manual
whatis ARGUMENT -> in some cases more useful then man command

head -n -> prints the first n line of a, let say, text file.

uniq -> report or omit repeated lines
	argument -u afiseaza liniile fara duplicate
	argument -d afiseaza doar liniile cu duplicate
	argument -c afiseaza nr e aparitii a fiecarei linii
	!!! NOTE : trebuie folosit cu sort

sort -> sorteaza liniile dintr-un fisier, sau cuvintele dintr-o linie
	argumentul -f nu tine cont de litere mari sau mici
	argumentul -n sorteaza valori umerice ( ignora stringurile ) 

cut -> ia inpututl si-l interpreteaza ca n tabel pe baza unui separator din care putem alege coloanele
       e.g. cut -d: -f1,5 ( delimitatorul  : ) ( iau coloanele 1, 5 )

sed ->  inlocuieste in fisier, fata de grep care doar cauta.
	e.g. sed s/ana/Ana/g fisier.txt -> peste tot in fisier se inlocuieste ana cu Ana
	e.g. sed s/abcd/ABCD/ fisier.txt -> a mic se face A s.a.m.d e ca o tabela de translatatie
	-> se folosesc expresii regulare

-----------------------------------------------------------------------------------------------------------------
awk ->  mai puternic decat grep. 
	e.g. awk '{print $2}' fisier.txt -> al 2 cuvant de pe fiecare lini din fisier.
	e.g. awk '{print $2,NF}' fisier.txt -> nr de cuvinte de pe linie separate prin spatiu si al doilea cuvant
	e.g cat fisier | awk -f arg.awk -> scriem in fisierul arg.awk ce am scrie intre paranteze

REGULAR EXPRESIONS : 

. -> Matches any single character 
\ -> Escape, changes the meaning of the character following it, between normal and special 
[abc] ->  Matches any single character that appears in the list (in this case a or b or c) 
[a-z] -> Matches any single character that belongs to the range (in this case any lower-case letter) 
[^0-9] -> Matches any single character that does not belong to the range (in this case anything that is not a digit) 
^ -> Beginning of line 
$ -> End of line 
\< -> Beginning of word 
\> -> End of word 
( ) -> Group several characters into an expression 
* -> Previous expression zero or more times 
+ -> Previous expression one or more times 
? -> Previous expression zero or one times 
{m,n} -> Previous expression at least m and at most n times or just {x} x times
| -> Logical OR between parts of the regular expression
